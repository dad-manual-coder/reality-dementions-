# reality-dementions

A single-page interactive visualization exploring theoretical dimensions from 0D to 11D.

## Search & discovery

This project is intentionally designed as a lightweight static experience. To make it more discoverable, use the repository's searchable documentation and sitemap files:

- `SITE_MAP.md` — human-readable site map and search keywords
- `sitemap.xml` — machine-readable sitemap for crawlers
- `robots.txt` — indexing instructions for search engines

## Repository purpose

The app presents a dimensional observatory: a visual and mathematical walk-through of singularities, line and plane constraints, 3D reality, hyperspace projection, probability landscapes, compactified dimensions, and M-theory.

## Entry point

- `index.html` — the main single-page app
