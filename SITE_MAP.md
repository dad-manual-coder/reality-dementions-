# Reality Dimensions — Searchable Site Map

## Project summary

This project is a single-page interactive web experience called "Dimensional Observatory." It presents a visual exploration of mathematical and theoretical conceptions of dimensions from 0D through 11D, including singularities, line and plane constraints, 3D volume, hyperspace, probability landscapes, compactified dimensions, and M-theory.

## Primary page

- `index.html` — main interactive page
- Live site: https://reality-dementions.vercel.app/
