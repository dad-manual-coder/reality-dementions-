# Reality Dimensions — Searchable Site Map

## Project overview

This repository contains a single-page interactive experience titled "Dimensional Observatory." The site explores the mathematical and conceptual ideas behind dimensions from 0D to 11D, including singularities, linear constraints, planar surfaces, physical volume, hyperspace projection, probability landscapes, compactified dimensions, and M-theory.

## Primary entry point

- `index.html` — main interactive web page and visualization

- Mathematical state: zero spatial extent
- Keywords: singularity, point, origin, dimensionless coordinate

- Mathematical state: length along a single axis
- Keywords: line, axis, linear, one-dimensional, segment

- Mathematical state: width and height only

- Mathematical state: our experienced spatial reality
